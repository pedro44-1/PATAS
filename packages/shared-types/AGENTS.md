# Shared TypeScript types

## Purpose

Own `@patas/shared-types`, the TypeScript representation of public PATAS domain contracts.

## Ownership

Source types live in `src`; `dist` is generated by the package build and is not hand-maintained.

## Local Contracts

- Keep exports stable and explicit through the package barrel and `package.json` export map.
- Match backend Pydantic field names, optionality, and status literals.
- Keep temporary-password identity state and owner/pet archive fields synchronized with backend responses.
- Avoid introducing frontend-only UI state into shared API/domain types.

## Work Guidance

When a backend public schema changes, update the relevant type, barrel/export map if needed, frontend API consumers, and API documentation together.

## Verification

Run `npm run build --workspace=@patas/shared-types` from the repository root.
